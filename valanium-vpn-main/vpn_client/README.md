# Valanium VPN — Desktop Client (MainScreen)

Rust + [Tauri](https://tauri.app) desktop client. The UI is plain HTML/CSS/JS
rendered in the OS webview (WebView2 on Windows), driven by a small Rust
backend (`src-tauri`).

Matches the mockup in `../../Downloads/gffgddfg/MainScreen.png`: world map
with a pulsing marker on the active server, a right-hand sidebar with search,
a settings gear, per-country server cards (flag / load / ping, highlighted
when "Current"), and a footer crediting valanium / the ObsyXgen protocol.

## Layout

```
vpn_client/
  src/                   frontend (served by Tauri's webview)
    index.html
    style.css
    main.js              calls Tauri commands via window.__TAURI__.core.invoke
    assets/map.svg        original design export (decorative coastline art, unused)
    assets/map-fill.svg   solid-fill Northern/Western Europe map, actually used —
                          generated by tools/build_map.py, see below
  src-tauri/             Rust backend
    src/main.rs           Tauri commands: list_servers, get_status, connect, disconnect
    src/servers.rs        ServerInfo model + placeholder server list (with real
                          lat/lon-projected map_x/map_y per server)
    src/vpn.rs            connection state machine (stubbed)
    Cargo.toml, tauri.conf.json
  tools/build_map.py      regenerates assets/map-fill.svg from Natural Earth data
```

## The map

`assets/map.svg` (the original design export) turned out to be a decorative
coastline texture — a single SVG path drawn as a thin stroke-shaped fill, with
no distinct fillable countries, cropped from a much larger repeating pattern.
It couldn't show a real solid landmass or place servers at their actual
countries.

`assets/map-fill.svg` replaces it: real country polygons from
[Natural Earth](https://www.naturalearthdata.com/) (1:110m admin-0 boundaries,
public domain, no attribution required), reprojected to a simple equirectangular
SVG and cropped to Northern/Western Europe — regenerate it with
`python tools/build_map.py` after editing `REGION_VIEWBOX` in that script if
the crop needs to change. Because it's a real projection, each server's
`map_x`/`map_y` (in `servers.rs` and `main.js`) is that country's actual
capital coordinate, not a guessed decorative spot — see the projection math
at the top of `build_map.py`.

The volumetric look (raised/embossed coastline, glowing "current location"
dome, camera zoom-to-marker) is all CSS on top of that solid map: see
`.map-relief*` (bevel/bloom mask layers), `.map-glow`, and `.map-viewport` in
`style.css`.

## Running it

Requires the Rust toolchain (`rustup`) and the Tauri CLI — neither is
installed in this environment, so this hasn't been built/run here.

```bash
# one-time
cargo install tauri-cli --version "^2"
# from vpn_client/
cargo tauri dev
```

## Previewing the UI without Rust

`src/main.js` detects `window.__TAURI__` and falls back to an in-memory mock
backend (same shape as `servers.rs`/`vpn.rs`) when it's missing, so the
MainScreen can be opened directly in a browser for design review:

```bash
cd vpn_client/src
python -m http.server 8931
# open http://localhost:8931/index.html
```

## Вход и ключи

Учётная запись — код доступа, как номер счёта у Mullvad: ни почты, ни имени,
ни пароля. Отличие в том, что код тратится **один раз**, на привязку
устройства (`identity.rs` заводит пару Ed25519 и подписывает ей nonce), а
дальше клиент входит подписью. Кода на проводе больше нет.

| Файл | Что делает |
| --- | --- |
| `src-tauri/src/identity.rs` | ключ устройства, завёрнутый в DPAPI рядом с exe |
| `src-tauri/src/api.rs` | клиент `/v1`: hello, enroll, auth, account, devices, peer |
| `src-tauri/src/wg_keys.rs` | пара WireGuard **на каждый узел**, сборка конфига |

Приватный ключ WireGuard рождается здесь и наружу не уходит: сервер получает
только публичную половину. На каждый узел заводится своя пара — один ключ на
все узлы позволил бы операторам двух узлов сшить по нему две сессии одного
человека.

Учётных данных сервиса в бинарнике нет. Адрес плоскости управления
переопределяется переменной `VALANIUM_VPN_API` — для своего сервера и для
отладки.

### Сборка

```bash
cd vpn_client/src-tauri
cargo build --release
```

Готовая программа — это `valanium-vpn.exe` рядом с `wireguard.dll`
(`src-tauri/bin/wireguard.dll`): без библиотеки окно откроется, но
подключиться не сможет. Отдельный установщик не нужен, `cargo tauri build`
собирает его же плюс msi.

### Диагностика без окна

Релизная сборка идёт с `windows_subsystem = "windows"`, консоли у неё нет —
каждая команда пишет свой файл рядом с exe.

| Команда | Что делает | Пишет |
| --- | --- | --- |
| `--enroll <код>` | привязать устройство кодом доступа | `enroll.log` |
| `--status` | вход подписью, аккаунт, узлы, устройства | `status.log` |
| `--test-wg <id> <сек> [mask]` | поднять настоящий тоннель на N секунд | `test-wg.log` |

`--status` в сеть машины не лезет вовсе. `--test-wg` — лезет: он заворачивает
в тоннель весь трафик и требует прав администратора, поэтому вынесен
отдельной командой, а не спрятан внутрь проверки входа.

## Чего ещё нет

- **killswitch.** Переключатель в настройках отключён и помечен: при обрыве
  тоннеля трафик уходит в открытую сеть. Нужен фильтр WFP.
- **IPv6.** `wg_nt.rs` разбирает только IPv4 в `AllowedIPs`, поэтому на хосте
  с IPv6 этот трафик идёт мимо тоннеля.
- **Запуск с Windows и автоподключение** — переключатели тоже отключены.
- **Задержка и загрузка узлов** приходят нулями: раньше клиент мерил время до
  открытого порта панели, но панель больше не смотрит в мир, а адреса узлов
  клиенту не отдаются намеренно. Настоящие числа должен присылать сам узел.
