# Выбор сообщений, чатов и редактор фото

Изменения находятся в Android- и Windows-клиентах **этого монорепозитория**. Отдельные старые клиентские репозитории не являются источником этих изменений. Сервер и формат сообщения не меняются.

## Управление

- Android: удержание сообщения или диалога включает выбор. Дальнейшие касания добавляют и убирают элементы. Системная панель показывает количество и общие действия. «Назад», переход на другой экран и уход приложения в фон завершают выбор. Также есть пункт «Выбрать» в меню сообщения.
- Windows: Ctrl/Cmd + щелчок по сообщению или «Выбрать» в его контекстном меню. Для диалогов — правый щелчок по строке, затем обычные щелчки по другим строкам. Escape/«Отмена» завершают выбор.
- Копирование объединяет текст выбранных сообщений в порядке переписки, разделяя их переводом строки. Вложения без текста пропускаются.
- Групповое удаление требует подтверждения и удаляет данные **только на этом устройстве**. Удаление у обоих остаётся отдельным действием для собственного сообщения.
- Если все выбранные диалоги уже закреплены, действие снимает закрепление. Иначе закрепляет все выбранные. Закрепления хранятся локально, отдельно для каждого аккаунта, и поднимают диалоги в начало списка. Групповые беседы Windows также можно выбирать; их удаление использует существующее локальное «Забыть группу», без уведомления других участников.

## Фото

В просмотре фото из сообщения есть «Изменить и отправить» — для входящих и исходящих изображений. Результат отправляется новым сообщением с новым ID исходному собеседнику, исходное сообщение сохраняется. Просмотр аватара не предлагает пересылку его как сообщения.

Редактор поддерживает цветную кисть, выбор толщины и отмену последнего штриха. Штрихи входят в экспорт JPEG и следуют повороту/отражению изображения. Сброс удаляет рисунок вместе с прочими правками.

Масштаб просмотра не меняет кадр в координатах исходного изображения и не меняет экспорт. При увеличении перетаскивание двигает просмотр, а углы рамки изменяют кадр. Изображения и рисунки обрабатываются в памяти; EXIF не переносится в экспортируемый JPEG.

## Проверки

В `valanium-windows`:

```sh
npm ci
npm test
npx playwright install chromium
npm run test:ui
```

Для установленного Chromium можно передать `CHROMIUM_PATH`. Браузерная проверка использует локальный HTTP-сервер и имитацию команд Tauri; проверяет порядок копирования, закрепления, привязку удаления к исходной беседе, выбор разделителей, неизменность экспорта при масштабе, рисунок/отмену и получателя фото. Она не заменяет запуск Windows-бинарника с настоящим ядром.

Android-исходники проверены компиляцией Java с Android API 35 и разбором XML. APK/ресурсная сборка и проверка жестов на реальном устройстве в этой сессии не выполнялись.

Варианты сетевого переноса аккаунта описаны отдельно в [account-pairing-proposal.md](account-pairing-proposal.md); это проект протокола, а не уже включённая функция.
