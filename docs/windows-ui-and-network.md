# Windows 0.13.7

Экран регистрации использует сид-фразу, основной выбор действия и строку выбранного подключения. Отдельный чекбокс Tor удалён. Оставшиеся чекбоксы приложения оформлены переключателями, без системного вида WebView. В настройках доступны только Auto и Tor; новые установки используют Tor. Старые Basic, Multi-hop и неизвестные значения переводятся на Tor. Явно выбранный Auto сохраняется.

Технические схемы, выбор узлов и неработающие варианты маршрутов убраны. Сведения о цепочке Tor находятся в раскрывающемся разделе. Загрузка исполняемого компонента остаётся отдельным действием с проверкой подписи и хеша, а не скрытым сетевым запросом.

## Исправления подключения

- Локальный аккаунт открывает экран чатов сразу, даже если подготовка Tor ещё продолжается или завершилась ошибкой. Пользователь может читать локальную историю и открыть настройки.
- Один контроллер запускает соединение при входе, смене режима, применении приватного профиля и ручном повторе. Номер поколения отменяет устаревший результат подготовки: поздний запуск Tor не возвращает прежний маршрут после переключения на Auto.
- Auto сразу пробует свой маршрут и параллельно подготавливает установленный Tor для резерва. Отсутствующий компонент не скачивается автоматически.
- Отказ Tor оставляет выбранный Tor без перехода на прямое подключение. Кнопка повторного подключения доступна в настройках.
- После ручного запуска Tor существующий аккаунт переподключается. Ручная остановка разрывает Tor-сеанс; обнаруженная остановка процесса во время работы приложения запускает повторную подготовку.

## Проверка

14 тестов Windows проверяют миграцию настроек, отсутствие паролей аккаунта, подготовку Tor без автоматической загрузки, ошибки запуска, гонку смены режима и открытие локального UI до подключения.

На Windows запущен установленный Onionize с отдельным временным каталогом состояния. Первый запуск занял около 70 секунд. HTTPS health-проверка и WebSocket HELLO прошли для прямого входа; HTTP health и WebSocket HELLO — для основного onion-входа; WebSocket HELLO — для второго onion-входа.

`valanium-core/examples/transport_probe.rs` открывает WebSocket с теми же заголовками, проверяет HELLO и закрывает соединение. Проверка не создаёт аккаунт, не открывает пользовательскую базу и не отправляет сообщения. Она подтверждает доступность транспорта и начального протокола; реальная переписка пользовательского аккаунта этим запуском не проверялась. UI проверяется браузерным стендом с подменённым мостом Tauri отдельно от живого сетевого теста.
