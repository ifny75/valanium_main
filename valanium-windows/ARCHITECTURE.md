# Архитектура Windows-клиента Valanium

Tauri 2 линкует Rust-ядро напрямую. WebView2 отображает интерфейс и передаёт
JSON-команды через Tauri; события ядра возвращаются в интерфейс. MLS,
ключи, запечатанная SQLite и сетевые задачи исполняются в Rust.
Веб-интерфейс получает открытый текст и является частью доверенного клиента.

## Сообщения и действия

`src/main.js` отображает историю и открывает меню сообщения. Правка
доступна только своим подходящим сообщениям. Для горизонтального pointer-жеста
исходный прямоугольник пузыря сравнивается с видимой областью списка
с учётом padding. Исходящий сдвигается влево, входящий — вправо.

Логическое расстояние до открытия меню не зависит от видимого смещения.
Перемещение ограничено оставшимся местом до краёв. Pointer capture сохраняет
жест при выходе указателя за маленький пузырь. `pointercancel` сбрасывает
визуальное состояние без меню; чужой pointerId не завершает активный жест.
`touch-action: pan-y` сохраняет нативную вертикальную прокрутку.

Проверка: `npm test` и `node --check src/main.js`. Node-тесты не подменяют
проверку в WebView2. `npm run build` собирает приложение с `--no-bundle`;
установщики и подпись требуют отдельной процедуры на Windows.

## Ядро и выпуск

Ядро подключено локально из `../valanium-core`; отдельный git-репозиторий клиента использует закреплённый SHA.

Анонимная доставка, билеты, пропуска, MLS и серверные ACK реализуются в
общем ядре. Разные пункты маршрутизации в версиях UI не гарантируют
доступности старого relay/Multi-hop. Согласованность ядра и сервера проверяется
по HELLO и исходникам, а не только по номеру версии оболочки.

Полная модель протокола, Tor и доверия —
[valanium_main/ARCHITECTURE.md](https://github.com/ifny75/valanium_main/blob/main/ARCHITECTURE.md).
